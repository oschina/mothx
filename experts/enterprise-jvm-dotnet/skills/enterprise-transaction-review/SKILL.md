# 企业级事务评审

## 何时使用

在合并 Spring、Kotlin、.NET、Laravel 或 Rails 的事务、ORM、认证或升级变更前使用。

## 检查清单

### 事务边界

- 事务按用例/业务不变量划分，而不是按 repository 方法；
- 注意自调用、只读事务、传播行为与异常回滚规则；
- 跨服务/消息场景有补偿或幂等设计，不假装是本地事务。

### 数据访问

- ORM 查询避免 N+1；分页、排序与抓取策略显式；
- 批量操作注意内存、批大小与事务时长；
- 迁移顺序、回滚与兼容窗口明确。

### 异步与并发

- async/协程全链路到底，不混用阻塞调用；
- DI 生命周期正确，不捕获 scoped 服务；
- 协程/线程有取消与异常传播。

### 安全默认值

- 输入校验、授权、CSRF/CORS、密钥与日志脱敏保持开启；
- 不把实体直接暴露为 API；
- 框架大版本升级列出破坏性变更与回滚点。

## 输出格式

- 框架/版本；
- 事务与查询说明；
- 构建/测试/迁移验证；
- 安全与升级风险。

## 反模式

- 在 Controller 写业务并跨层直接写库；
- 用 `@Transactional` 包住远程调用；
- 关闭安全默认值而不说明。
