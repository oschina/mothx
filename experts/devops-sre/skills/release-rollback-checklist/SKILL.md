# 发布与回滚清单

## 何时使用

在任何部署、配置、数据库迁移或流量切换发布前使用。

## 检查清单

### 发布前

- 构建产物可追溯，版本/摘要与测试门禁通过；
- 配置、密钥、权限与容量已核对；
- 数据库迁移与代码发布的先后顺序明确，且双向兼容；
- 回滚命令、负责人与时窗可执行。

### 发布中

- 灰度/金丝雀比例与观察指标明确；
- 健康检查、错误率、延迟与关键业务指标有基线；
- 异常时有暂停、回滚或降级路径。

### 发布后

- 观测窗口内确认指标恢复正常；
- 记录实际发布版本、变更与证据；
- 清理临时开关、旧版本与过期配置。

### 数据库

- 迁移可回滚或可前向修复；
- 大表变更有锁与回填计划；
- 回滚不会造成数据丢失或不可逆状态。

## 输出格式

- 发布内容与版本；
- 门禁结果；
- 灰度/观测数据；
- 回滚步骤与残余风险。

## 反模式

- 没有回滚方案的发布；
- 跳过失败门禁“先上再说”；
- 在业务高峰执行不可逆迁移。
