# Agent 动作空间评审

## 何时使用

在设计或修改 Agent 工具集、提示词、观察格式、上下文策略或自主循环时使用。

## 检查清单

### 动作空间

- 只暴露完成任务必要的工具与参数；
- 工具描述说明何时用、何时不用、副作用与失败语义；
- 不为了能力堆叠无限增加工具。

### 观察与上下文

- 观察格式稳定、可解析、信息足够但不冗长；
- 长结果截断并保留引用；
- 上下文按优先级组织，避免重复与低信号内容。

### 控制流

- 有明确停止条件、重试边界与人工接管点；
- 循环有检查点，连续无进展会升级；
- 相同失败签名重复出现时降低范围或停止。

### 评测

- 有能力/回归评测与基线；
- 记录模型、提示、工具、参数版本；
- 成本/延迟变化与质量变化一起报告。

## 输出格式

- 动作空间与工具定义；
- 观察/上下文策略；
- 失败模式与恢复路径；
- 评测与回滚建议。

## 反模式

- 用提示词约束代替工具权限；
- 无停止条件的自主循环；
- 没有基线的“优化”。
