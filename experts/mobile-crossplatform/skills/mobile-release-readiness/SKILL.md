# 移动端发布就绪

## 何时使用

在 Android、Flutter、React Native、iOS 或 KMP 功能进入发布候选前使用。

## 检查清单

### 平台与生命周期

- 目标平台、最低系统版本与设备覆盖明确；
- 前后台切换、配置变更、进程重建与深链路径完整；
- 权限请求有拒绝/永久拒绝/引导设置路径；
- 平台差异显式分支，不靠隐式 fallback。

### 数据与离线

- 网络失败、超时、重试、缓存与离线状态有明确行为；
- 本地存储迁移/清理不会丢用户数据；
- 敏感数据加密，日志不输出令牌或个人信息。

### 性能与资源

- 列表使用虚拟化/复用，图片与动画注意内存；
- 启动时间、滚动流畅度与包体有基线；
- 原生桥接说明类型、错误、线程与生命周期。

### 发布

- 版本号、构建号、签名/证书与商店能力变更已核对；
- 崩溃/分析/灰度与回滚路径可用；
- 隐私清单、权限说明与审核材料齐全。

## 输出格式

- 平台/版本覆盖矩阵；
- 阻塞项与设备证据；
- 构建、真机/模拟器验证结果；
- 商店审核与回滚风险。

## 反模式

- 只在模拟器验证就宣称发布就绪；
- 用重试掩盖网络失败；
- 忽略权限拒绝后的永久不可用路径。
